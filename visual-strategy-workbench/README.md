# 视觉策略 AI 工作台

本项目是网页端 demo，用于上传产品资料压缩包、可视化查看资料、手动添加每一步 `.md` 规则，并生成产品事实、市场分析和视觉策略结果。

## 本地运行

复制环境配置：

```bash
copy .env.example .env
```

默认配置为离线模式：

```env
LLM_MODE=offline
```

离线模式不会发起任何大模型 API 请求，可用于验证本地链路、项目保存、压缩包解析、规则插口和页面交互。

## 接入真实或内网模型

如果公司网络允许访问模型服务，或已部署内网 OpenAI-compatible 模型接口，将 `.env` 改为：

```env
LLM_MODE=api
LLM_API_KEY=模型服务 Key
LLM_BASE_URL=模型服务地址
LLM_MODEL=文本模型
LLM_VISION_MODEL=多模态模型
```

## 输入约定

- 项目资料通过 `.zip` 上传，资料包是产品信息的唯一入口，不需要在左侧单独填写产品字段。
- 压缩包内第一版支持 `.md`、`.txt` 和图片文件。
- 上传后，工作台会将图片与文本资料展示为文件卡片。
- Excel 第一版暂不处理。
- 每一步规则由前端规则控制台单独上传 `.md` 文件。
