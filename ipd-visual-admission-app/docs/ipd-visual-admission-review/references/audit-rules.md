# 审核规则

## 1. 资料优先级与召回

优先级固定为：产品营销资料对接包 80%，产品说明书 15%，其他资料 5%。

召回顺序：

1. 查找产品营销资料对接包；找到则执行其中的相关检查。
2. 未找到营销资料时查找产品说明书；找到则执行说明书相关检查。
3. 两者都未找到时读取其他资料，仅用于定位产品范围、责任人和一票退回线索。

“其他项不检查”与 5% 权重存在边界：本版不评价其他资料完整度。因此完整度报告使用 `已检查原始分 / 95`，并给出等效百分制；剩余 5 分固定标为 `未审计`，不得由模型自行发放或扣除。

## 2. 完整度评分

完整度只检查字段是否存在且非空、可读、与所属条目有关联；不评价表述优劣、证据是否真实或卖点是否成立。

### 产品营销资料对接包：80 分

| 模块 | 满分 | 必填检查项 |
| --- | ---: | --- |
| PMF-JTBD 用户洞察 | 20 | 场景触发、任务动机、体验痛点、瘾点/复购点、晒点/传播点、核心洞察结论、顾客典型心理路径、企业分析点。每项 2.5 分。 |
| PMF-用户画像 | 10 | 至少能识别目标人群、基础特征、需求/动机、痛点、消费/使用特征。每项 2 分。 |
| VOC 竞对报告 | 15 | 评论原声、竞对 VOC 报告、横向对比报告。每项 5 分。 |
| GTM 信息包：Feature 基础卖点与场景 | 25 | 卖点排序、产品人视角、用户视角、F 设计特征、A 功能优势、B 顾客利益、E 证据/图示、参考；场景排序、场景与说明、人群特征、场景痛点与动机。共 12 项，每项 25/12 分。 |
| GTM 信息包：RTB 值得信赖的理由 | 10 | 表格内有专业报告/检测报告/专业依据的附件、链接或可定位引用。没有则 0 分。 |

### 产品说明书：15 分

按可识别且适用的字段等权评分：型号/SKU/版本、产品名称、成分/材质、规格或关键参数、尺码信息、功能/使用说明、适用范围或注意事项、质检/验证信息、责任主体或联系人。每项 `15 / 9` 分。

### 报告分数

- `raw_score`：营销资料得分 + 产品说明书得分，满分 95。
- `audited_completeness_percent`：`raw_score / 95 * 100`，四舍五入到 1 位小数。
- `unreviewed_weight`：固定 5，说明为“其他资料未纳入完整度检查”。
- 缺失营销资料或说明书时，相应模块为 0 分。

## 3. 输入信息排查

### 规则 1：USP 与 VOC

对每条 USP 逐条检查：是否能在 VOC 评论原声、竞对 VOC 或横向对比中找到对应的用户问题、竞品弱点或差异线索。输出不超过 200 个中文字符的总报告。

VOC 只可证明“用户/市场相关性”或“差异机会”，不能证明本产品功能。每条 USP 仍需本产品的证据定位；无证据时标记为 `核心卖点证据缺失`。

### 规则 2：功能性卖点的验证

功能性影响主张包括但不限于：弹力、提臀、收腹、支撑、塑形、防卷边、防滑脱、透气、抗菌、防晒、保暖、耐磨、耐洗、矫正、缓解或改善身体状态。

每条功能性卖点必须在产品说明书中找到对应的验证描述，并有质检报告、测试报告、专业报告或可追溯证据。仅有营销话术、竞品信息、VOC 或图片不算验证证据。

### 规则 3：卖点的真实展示方式

对每条基础卖点提出展示方案，至少包含：真实展示对象、画面/镜头、辅助图示或测量、可支撑的结论、限制条件。不得建议夸张变形、伪造前后对比、无法验证的效果示意。

判为 `展示困难` 的典型情形：无法通过实物、测量、真实使用过程或已提供的检测结果体现；需依赖不可见生理效果；只能用主观感受支撑绝对承诺。

示例中“高腰双层收腹 + 加宽防卷腰头”可建议：腹部双层实物特写、腰头宽度实测、平铺/拉伸结构图、真人久坐过程；普通单层对比仅可在同一条件下真实拍摄，且不得将视觉差异外推为未经验证的塑形效果。

### 规则 4：结论是否超出证据

对每条卖点拆分“事实、推断、结论”。若结论的对象范围、强度、持续时间、因果关系或绝对化程度大于证据，则标记 `超出证据范围` 并给出可接受的降级表述方向。审核不直接代写对外文案。

### 规则 5：使用场景是否稀释卖点

检查每个场景是否与 USP 的目标人群、使用动机和功能条件一致。若场景无法展示 USP、引入相反预期、使核心卖点退化为普通属性，或需要资料未覆盖的功能，则标记 `场景稀释`。

### 规则 6：Slogan 图片可感知性

检查 Slogan 所承诺的核心效果能否通过真实产品图、使用图、结构图、量测图或已提供报告的可视化引用直观感知。不可感知不等同于虚假，但不得作为视觉主标题的唯一支撑。

### 规则 7：USP 与关键流量词

检查关键流量词是否描述 USP 中可展示、可证实的内容。流量词扩大适用范围、承诺未验证功能或与 USP 无关时，标记 `关联弱` 或 `超范围`。USP 是视觉展现内容，必须同时具备本产品证据和展示路径。

## 4. 一票退回

任一项确认命中即 `不通过`：

1. 没有明确的型号、SKU 或产品版本。
2. 核心卖点没有本产品证据，或仅以竞品/VOC 作为产品证据。
3. 多份资料中的成分、参数、尺码或功能互相矛盾。

“核心卖点”优先读取 USP 和卖点排序靠前的基础卖点；若资料未标识，报告应明确这一假设并要求人工确认。

## 5. 责任人

每项问题应带 `owner`。优先读取资料中已有责任人；未提供时，使用责任角色建议而非具体人名：产品负责人（事实/参数）、质量或研发（测试/报告）、市场/GTM（卖点/VOC/流量词）、视觉负责人（展示可行性）。
