## USP 与视觉

资料事实：VOC 指向防破、卷边、起球、尺码不准、肤色断层等用户痛点，与双层腰头、透肤保暖、高弹尺码包容等 USP 方向相关。

审核推断：该关联只能证明市场机会，不能证明 NC3634A 的功能。尤其 `tummy control`、`butt lift`、`thermal` 相关对外主张必须先补本产品证据。

视觉建议：可如实拍摄双层腹部结构、6.5cm 腰头量测、面料成分、尺码、平铺/拉伸过程、不同尺码模特和冬季穿搭。未补测试前，画面不得被用于证明收腹程度、防卷时长、保暖强度、提臀效果或“永不掉档”。

## 整改后复审条件

1. 产品负责人统一最终尺码范围，并同步产品说明书、卖点说明、前端尺码表、GTM 和视觉任务。
2. 质量或研发提供本产品的可追溯测试/质检资料，至少覆盖保暖、拉伸回弹/掉档、腰头卷边/滑脱、洗后起球；提臀或塑形主张如保留，也需对应验证路径。
3. RTB 提供实验报告附件、链接或报告编号，并包含样品、方法、判定标准及结论。
4. 产品负责人明确 `NC3634` 与 `NC3634A` 的 SPU/款号或版本映射。

责任人：尺码和范围映射由产品负责人；测试与 RTB 由质量或研发；广告词与卖点降级由市场/GTM；实拍方案及素材边界由视觉负责人。
